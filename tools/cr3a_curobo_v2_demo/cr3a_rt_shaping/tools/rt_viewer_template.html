CR3A 실시간 장애물 회피 — WMX 로그 재생

    3D 보기

    관절 (°)

    다리 (누르면 그 구간으로)

    닿음 — 실제 형상 (Dobot 메시) 거리 < 0 (누르면 0.6 s 앞부터 0.25× 로 재생)

    관절 고르기
    • 실선 = 보낸 명령: cuRobo MPC 목표를 명령 생성기가 속도·가속·저크 한계 안에서 만든 5 ms 궤적 (JTC 로 보낸 값)
    • 점선 = WMX 엔진 명령
    • 관절을 하나만 고르면 실선·점선을 비교하기 쉬움

    관절 위치 (°)

    • 점선 = WMX 엔진 명령 위치 (CMDPOS)

    관절 속도 (°/s)

    • 점선 = WMX 엔진 명령 속도 (CMDVEL)

    관절 가속 (°/s²)

    • 점선 = WMX 명령 속도의 10 ms 변화 ÷ 10 ms
    • 가속이 한계 (관절 1·2 ±360, 3~6 ±446 °/s²) 사이를 오가는 이유: 명령 생성기가 목표점을 가장 빨리 쫓는 방식

    입력성형 확인

    WMX 명령 − 전체 컨볼루션 (mrad, 관절 각변위)

    명령 전달: 보낸 명령 → JTC (10 ms) → R2 (1 ms 점으로 쪼갬) → CyclicBuffer → WMX 엔진

    엔진이 본 1 ms 가속 (rad/s², 관절별)

    WMX 명령 − 보낸 명령 (mrad, 전달 지연을 맞춘 뒤)

    명령을 보낸 여유 (ms)
